# EduGenie

EduGenie is a small educational assistant with a FastAPI backend and a responsive HTML, CSS, and JavaScript frontend. It supports question answering, simplified explanations, topic quizzes, structured learning paths, and passage summaries.

## Run locally

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000). Without model settings the app runs in demo mode. The demo includes the largest-ocean answer, a Pythagorean theorem quiz, a general learning-path template, and a basic opening-sentence summary. Demo answers are labeled and are not generated by an AI model.

## Connect an AI model

EduGenie accepts any OpenAI-compatible chat-completions endpoint. Set these environment variables before starting the server:

```bash
export AI_API_KEY="your-provider-key"
export AI_MODEL="gpt-4o-mini"
uvicorn app.main:app --reload
```

`AI_API_KEY` and `AI_BASE_URL` are optional. The default base URL is `https://api.openai.com/v1`. For a local Ollama server, for example, set `AI_BASE_URL=http://localhost:11434/v1` and `AI_MODEL` to a model you have installed; no API key is needed for a local endpoint. See [.env.example](.env.example) for the available settings. Do not commit real API keys.

The configured model receives the selected action, learner level, and submitted topic or passage. The browser labels AI-generated content and reminds learners to verify important facts against course materials.

## API

- `GET /api/status` reports whether a model endpoint is configured.
- `POST /api/study` accepts `action` (`ask`, `simplify`, `quiz`, `path`, or `summarize`), `content` (up to 12,000 characters), and an optional `level` (`beginner`, `intermediate`, or `advanced`).
- `GET /docs` opens the interactive FastAPI documentation.
